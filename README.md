# MikanXR.github.io

The organization site served at [mikanxr.org](https://mikanxr.org).

Plain static HTML, no build step. `.nojekyll` disables Jekyll processing, and `CNAME` holds the custom domain. Edit `index.html` and push to `main` to publish.

Project sites for other repositories in this organization are served underneath this domain at `mikanxr.org/<repository>`.
