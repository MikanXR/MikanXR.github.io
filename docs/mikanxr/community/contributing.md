# Contributing

- Code under `src/` is formatted with clang-format and enforced by CI. See [CONTRIBUTING.md](https://github.com/MikanXR/MikanXR/blob/main/CONTRIBUTING.md).
- The UI text is currently machine translated. Improving it needs no build and no C++, just [POEdit](https://poedit.net/) and a pull request. See [the translation guide](https://github.com/MikanXR/MikanXR/blob/main/docs/TRANSLATING.md).
- These docs live in the [MikanXR.github.io](https://github.com/MikanXR/MikanXR.github.io) repository. Every page has an "Edit this page" link at the bottom.
