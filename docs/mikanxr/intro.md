# MikanXR

MikanXR is a Windows tool for mixed reality camera calibration and video compositing. The editor calibrates a physical camera against your VR tracking system, then composites the layers that client applications render over the live video feed.

:::warning[Under development]

MikanXR is still heavily under construction and is not really in a usable state yet. Expect rough edges.

:::

## Where to start

- [Installing](./getting-started/installing.md) covers prebuilt releases.
- [Initial setup](./getting-started/initial-setup.md) covers the first run.
- [Building from source](./getting-started/building-from-source.md) is for modifying or debugging the tool.

Most setup guides and troubleshooting notes still live on the [project wiki](https://github.com/MikanXR/MikanXR/wiki). They will move into these docs over time.

## How these docs are organized

- **Tutorials** walk through a complete task from start to finish.
- **How-to guides** answer one specific question.
- **Reference** lists settings, file formats, and the client API.
- **Concepts** explain how MikanXR works and why.
